# Documentation

Guides for using albam. For how the code is organised, read the repo's
`CLAUDE.md`; for a format's own fields, read the `.ksy` files under
`albam/engines/*/structs/`, which carry what is known about each one. How the
formats relate to each other is in the guides, since no single `.ksy` can say
it.

## Guides

- [Modding a character (RE4UHD)](modding-a-character.md) - importing
  a character, changing it, and getting it back into the game, with the checks
  worth running before you do. Includes how the archives, models, texture lists
  and texture banks fit together.
